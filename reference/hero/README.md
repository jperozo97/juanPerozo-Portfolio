# Hero prototypes (single-file HTML, open in a browser)

None is final. Port the mechanics to React client components, do not copy the files as-is.

| File | Idea | Status |
|---|---|---|
| hero-motion-blur.html | Cinematic blurred light (WebGL directional blur), giant translucent name, serif italic. Has an "Add my photo" button to try a real photo. | Liked a bit more. Use as hero v1 base. |
| hero-portrait-ui.html | Portrait rebuilt from UI pieces (dots, bars, pills, cards). A lens reveals the real photo. Needs his photo. | Original idea, untested with his photo. |
| hero-sketch-ink.html | Pencil sketch of the Fedes panel that gets inked in color by the cursor. | Not convincing. |
| hero-3d-object.html | Liquid chrome object (shader) with giant name. | Too generic. |
| hero-3d-prototype.html | Floating UI layers separating on scroll (three.js). | Not impactful enough. |

Notes
- three.js prototypes load three r128 from cdnjs. In the real project install `three` from npm.
- Textures are drawn in code as placeholders. Real project screenshots and a real photo are what will make any of these feel authentic.
