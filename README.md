# Juan Perozo — Portfolio (starter kit)

This folder is the hand-off from the design exploration to Claude Code.

## What is inside
- `CLAUDE.md`: project context. Claude Code reads it automatically.
- `docs/first-prompt.md`: the first message to paste into Claude Code.
- `docs/content.md`: all copy for the site (profile, About, experience, Fedes case with placeholders).
- `docs/deploy.md`: GitHub and Vercel steps, plus an important note about Vercel's free plan.
- `reference/hero/`: five single-file hero prototypes (open them in a browser).
- `reference/case-study/`: markup of the chosen case-study style ("Editorial light").

## Quick start
1. Install Git and Node.js (LTS), and install Claude Code.
2. Put this folder where you keep projects, open a terminal inside it and run `claude`.
3. Paste the prompt from `docs/first-prompt.md`.
4. Follow `docs/deploy.md` to create the GitHub repo and connect it to a host.
